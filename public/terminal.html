🎯 Stratégies PTL
Le terminal regroupe 13 modules pour lire le marché comme un institutionnel — de la macro aux setups PTL prêts à trader.
1
📋 Commence par MARCHÉS
Vue d'ensemble rapide : prix live, variation, signal composite sur toutes classes d'actifs. Identifie quels marchés sont en mouvement ce jour.
2
📊 Lis le COT + 👥 DMX
Le COT montre ce que font les hedge funds (positions CFTC). Le DMX montre le retail. Quand le retail est >75% Long, les institutionnels sont probablement Short — c'est ton signal contrarien.
3
📅 Vérifie la Saisonnalité
Historique 10 ans mois par mois. Si octobre est historiquement baissier sur EUR/USD ET le COT confirme → biais aligné = setup plus solide.
4
📉 Analyse sur CHARTS
Ouvre le graphique de ta paire. Choisis ton timeframe (H4 pour les setups PTL). Observe les EMA20/50/200 et cherche les structures de prix.
5
🎯 Valide via SETUPS PTL
Le terminal score automatiquement les 3 stratégies PTL. Un score 🔥 FORT (4/4) avec COT + Saisonnalité alignés = setup institutionnel de haute probabilité.
6
🤖 Demande l'analyse IA
Le bouton IA sur chaque ligne ouvre un panel d'analyse institutionnelle : biais, score, niveaux clés, macro, technique. Utilise-le pour confirmer ton biais.
⚠️ Note : Les données affichées sont simulées à titre éducatif. Connecte les API réelles (voir onglet API) pour des données live. Les stratégies PTL nécessitent toujours une confirmation chartiste manuelle.
💱 FOREX — Colonnes
BID / ASKPrix acheteur (vente) / Prix vendeur (achat). Le spread = ASK − BID.
SPREADCoût de transaction en pips. EUR/USD ~0.2 pip chez broker ECN.
SIGNAL▲ Haussier = momentum haussier · ▼ Baissier = momentum baissier · ◆ Neutre = range/consolidation.
'+gl('COT','COT')+'Biais institutionnel CFTC : Long = hedge funds acheteurs nets · Short = vendeurs nets.
DMX%% de retail Long. >75% = extrême long retail = signal baissier contrarien.
SAISONTendance saisonnière du mois en cours basée sur 10 ans d'historique.
📊 COT — Interprétation
>60% LongSignal haussier institutionnel — les smart money sont acheteurs.
>60% ShortSignal baissier institutionnel — les smart money sont vendeurs.
>80% extremeExtrême contrarien — retournement probable, surveiller de près.
NETNombre de contrats longs − shorts. Positif = net acheteur.
CHGVariation hebdomadaire du net. +grand = accélération du biais.
🔍 SCREENER — Scores
W%RWilliams %R. <−80 = oversold (opportunité achat). <−95 = extrême rare.
Score Buffett10 critères fondamentaux : ROE, dette, croissance BPA, FCF, moat, management… /10.
Score Global30% W%R normalisé + 70% Score Buffett. >75 = opportunité forte.
EXTRÊMEW%R < −95 : oversold extrême. Rare, signal très fort si fondamentaux bons.
FORTW%R < −90 : oversold fort. Signal solide.
🎯 SETUPS PTL — Scores
🔥 FORT 4/4Tous les critères automatiques validés. Setup de haute probabilité — confirmer sur chart.
⚡ MODÉRÉ 3/43 critères sur 4. Bon setup mais un filtre manquant — surveiller.
👁 SURVEILLER 2/4En cours d'alignement. Revenir plus tard.
Ring SVGCercle de progression du score : plein = 4/4, couleur or/vert/bleu selon intensité.
📉 CHARTS — Éléments
Corps vertBougie haussière : clôture > ouverture. Acheteurs gagnants sur la période.
Corps rougeBougie baissière : clôture < ouverture. Vendeurs gagnants sur la période.
Mèche hautePlus haut de la période — rejet des vendeurs au-dessus.
Mèche bassePlus bas de la période — rejet des acheteurs en-dessous.
EMA 20Moyenne mobile 20 périodes. Tendance court terme.
EMA 50Moyenne mobile 50 périodes. Tendance moyen terme.
EMA 200Moyenne mobile 200 périodes. Tendance long terme / golden cross.

Les 3 stratégies Process Trading Life sont intégrées dans le moteur de scoring du terminal. Chaque setup est noté de 0 à 4 selon les critères détectables automatiquement.
📐 S1 — Multi-Timeframe (MTF)
InstrumentsMajeures Forex + Métaux (EUR/USD, GBP/USD, XAU/USD…)
TimeframesAnalyse W1/Monthly pour biais → D1 pour structure → H4 pour entrée
Critères auto① COT institutionnel aligné ② DMX extrême contrarien ③ Saisonnalité favorable ④ Signal composite haussier/baissier
ConfirmationTrendline break, EMA100 non sur-extension, pattern (ETEi, double top/bottom) → manuel sur chart
🏗️ S2 — Double Structure
InstrumentsCrosses Forex (EUR/GBP, EUR/AUD, GBP/JPY…)
TimeframesD1 structure principale → H4 structure interne → H1/H4 entrée
Critères auto① COT cross aligné ② DMX extrême cross ③ Deux paires de la cross alignées ④ Signal composite fort
LogiqueIdentifier une structure externe (range/tendance D1) puis une structure interne (H4) dans le même sens pour timing précis
📈 S3 — Swing Action Market
InstrumentsActions croissance US/EU (NVDA, AAPL, MSFT, AMZN…)
TimeframesWeekly biais → Daily structure → H4 entrée
Critères auto① Tendance long terme haussière ② W%R oversold ③ Score fondamental Buffett ≥ 7/10 ④ Momentum volume
Patterns visésTriangle, drapeau haussier, double bottom, ETEi — confirmation manuelle obligatoire
🎯 Règle d'or PTL : Un setup scoré 🔥 FORT par le terminal est une alerte de haute probabilité. La validation finale = analyse chartiste manuelle (structure, pattern, point d'entrée précis, SL/TP). Le terminal te dit quoi surveiller, c'est toi qui décides quand entrer.
